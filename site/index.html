Connecting

Find what a sentence points to, and show the program that found it.

Spec-Guard answers a referring expression such as “the topmost peach of the fifth column from the left”. It first rewrites the expression into a fixed form. When that form passes a check that it states nothing the expression does not, a deterministic program answers; otherwise a code model writes one, and every program runs in a sandbox under checks.

Run a query Watch the pipeline run Browse the test set

M.Tech dissertation by MD Humayun (P25IS016), supervised by Prof. Mukesh A. Zaveri. Department of Computer Science and Engineering, SVNIT Surat.

  1. Normalise

    Qwen2.5-Coder-7B rewrites the expression into the template line the rule parser reads.

  2. Route

    If the line parses and every part of it is stated in the expression, a template program answers with no language model. Otherwise a program is generated.

  3. Execute and check

    The program runs over SAM 3, SigLIP 2 and Depth Anything V2 in a restricted sandbox. Spec-Guard checks the program and its answer.
